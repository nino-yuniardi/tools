Put it online with GitHub Pages
  1. On github.com create a new public repository, for example "tools".
  2. Open the repository, choose "Add file" then "Upload files", and drag in
     everything inside this folder (not the folder itself). Commit.
  3. In the repository go to Settings, then Pages. Under "Build and deployment"
     pick "Deploy from a branch", branch "main", folder "/ (root)". Save.
     After a minute the site is live at https://<your-username>.github.io/tools/
  4. When you are happy with it: in Settings, Pages, set the custom domain to
     tools.nino.studio, then in Squarespace domain settings point the "tools"
     record (CNAME) at <your-username>.github.io. This replaces the Base44 site.

Notes
  - Link previews (og tags) assume the site lives at https://tools.nino.studio
  - "Request a tool" opens an email draft to hello@nino.studio
  - Each tool keeps its numbers in the visitor's own browser
